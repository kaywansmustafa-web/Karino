\# Karino



Karino is a modern employment marketplace designed initially for Duhok and built for expansion across the Kurdistan Region.



\## Products



\- Job-seeker mobile app

\- Employer web dashboard

\- Karino admin dashboard



\## Technology



\- Flutter

\- Next.js

\- Supabase / PostgreSQL

\- Firebase Cloud Messaging

\- FIB payments

\- Server-side AI services



\## Business Model



\- Job-seeker access: 10,000 IQD / 30 days

\- Employer job posting: 15,000 IQD / vacancy

\- AI CV generation: 3,000 IQD

\- First public launch month: free job-seeker access



\## Development



Karino is built using controlled implementation sprints. Product and technical specifications in the docs folder are the source of truth.
